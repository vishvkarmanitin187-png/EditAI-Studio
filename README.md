# EditFlux Real Editor

Fresh React + Vite web editor with a real FFmpeg WASM export path.

## Run
npm install
npm run dev

## What is real here
- Local video import and playback
- Playhead and timeline
- Start/end trim controls
- Split point management
- Delete/duplicate timeline entries
- Speed control
- Brightness/contrast/saturation filters
- Rotate transforms
- Undo/redo for editor controls
- FFmpeg WASM MP4 export with trim/filter/rotation/speed

## Production roadmap
Audio mixing, text/sticker rendering, transitions, captions, background removal, cloud projects, accounts, payments and 4K server rendering need additional modules/backends. Do not put private API keys in frontend code.
