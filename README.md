EditFlux Web Editor
Mobile-first browser video editor starter.
Run:
Put index.html, style.css and app.js in the same folder.
Open index.html in a modern browser, or deploy the folder to Vercel.
For production, add a backend for authentication, AI APIs, ads, storage and FFmpeg/server-side 4K MP4 export.
